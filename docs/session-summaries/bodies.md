# Consysto Bodies — сводка по прошлым сессиям (на 12.10.2026)

Объединены сессии: «Consysto · Inventor · Сборка из тел: классификатор тел», «Consysto · Inventor · Autodesk App Store: заявка и продвижение на форуме», «Consysto · Inventor · Лицензирование дополнений».

## Что это
Надстройка Inventor «Сборка из тел»: из многотельной мастер-детали делает сборку из отдельных деталей. Репозиторий: github.com/egorcha174/ConsystoBodies.

## Сделано (июль 2026)
- Классификатор тел по операции-создателю (`CreatedByFeature`): Грань/Фланцы → листовая; Выдавливание/Вращение/Sweep/Loft → стандартная; зеркала и массивы (включая «Массив по эскизу») наследуют тип рекурсивно. На тестовой детали 43/43 без вопросов пользователю. Неизвестные операции (Coil, Rib и т. п.) уходят в диалог уточнения.
- Перенос тел через Derived Part с привязкой стилей листового металла; развёртка создаётся сразу; 9 параметров сборки связаны с мастер-деталью через DerivedParameterTable.
- Диалоги для пользователя и `silent`-режим для автотестов. Тогда изменения ждали команды на коммит — проверить, закоммичены ли.

## Общее для дополнений Inventor (лицензии и продажи)
Источники: «Consysto · Inventor · Лицензирование дополнений», «Consysto · Inventor · Autodesk App Store», «Consysto · Продвижение · Публикации в Telegram и оплата через Boosty».
- Библиотека лицензий готова в репозитории ConsystoStore (9 тестов проходят, в надстройки ещё не подключена, не закоммичена). Ключ `CSL1.…`, подпись сервера, проверка офлайн по открытому ключу. Виды: бессрочно + обновления на год; подписка (+7 дней льготы); бессрочно без условий. Привязка к компьютеру по идентификатору Windows. Утилита `consysto-keys` для ручной выдачи.
- Домен **consysto.pro** зарегистрирован. План: арендовать VPS в России (Timeweb/Selectel/Beget, Ubuntu 24.04, 1 ядро, 1–2 ГБ); сервер лицензий ASP.NET в Docker + Caddy (HTTPS) + SQLite: пробный месяц один раз на компьютер, активация с лимитом компьютеров, ручная выдача/отзыв, бэкап на .50. Почта license@consysto.pro через Яндекс 360. Почтовый бот активации — запасной путь для машин без интернета.
- Последний вопрос в той сессии: «Начинать?» (подготовку сервера лицензий) — ответа не было.
- Оплата: ЮKassa требует самозанятость и сайт на HTTPS с офертой; Boosty работает для России и СНГ (комиссия 11,7%), из Европы/США около половины платежей отклоняют банки — запасной вариант: счёт через посредника вроде Mellow. Продажи за рубеж упираются в юрисдикцию и приём платежей (Paddle/FastSpring/Stripe с продавцами из РФ не работают).
- Autodesk App Store: обсуждали заявку и продвижение на Autodesk Community Forums — сначала помогать в ответах, авторство раскрывать, не спамить; проверить, может ли аккаунт публиковать.

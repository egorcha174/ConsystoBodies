# Consysto Fill Pattern — сводка по прошлым сессиям (на 12.10.2026)

Объединена сессия: «Consysto · Inventor · Fill Pattern: заполнение отверстиями».

## Что это
Надстройка Inventor «Заполнение вырезами»: заполняет область детали массивом вырезов/отверстий (сетка, ступени, шахматный порядок, по контуру и т. п.) через массив по эскизу. Локально: `D:\CODES\ConsystoFillPattern` (`src\FillPattern.AddIn`), документ исследования `docs/RESEARCH.md` (раздел 8 — замеры). Репозитория на GitHub не найдено.

## Сделано (9 октября 2026)
- Ядро расчёта: 24/24 теста. Живые тесты в Inventor 2027.1: сценарии step-grid, step-deep, concave-slot, u-stagger, custom совпадают с расчётом; правка глубины тем же массивом; метаданные переживают переоткрытие; неудачная правка не меняет модель.
- Надстройка подключена: `%APPDATA%\Autodesk\Inventor 2027\Addins\ConsystoFillPattern.Inventor.addin`, DLL грузится из проекта (пересборка только при закрытом Inventor). Кнопка «Заполнение вырезами» на вкладке «3D-модель» — пока заглушка.
- Скорость: ~200 отверстий — 0,9 с создание / 1,5 с правка; ~500 — 1,7 / 3,7 с; ~1000 — 3,4 / 8,6 с. Inventor тратит ~2,4 мс на добавление и ~3,8 мс на удаление точки; неизменные точки не трогаются (вдвое быстрее). Переключить массив на новый эскиз нельзя (E_NOTIMPL).
- Исправлена ошибка ядра: числа не читались, если состояние собирал код.
- Ничего не закоммичено.

## Открыто — следующий шаг на выбор
1. Поворот выреза на каждом месте (кольца «по радиусу/касательной» пока отклоняются).
2. Мастер: выбор граничного эскиза, панель, превью; индикатор хода для ~1000 отверстий.
